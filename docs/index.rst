**apache-guacamole-mcp** is a `Model Context Protocol <https://modelcontextprotocol.io/>`_
(MCP) server that wraps the `Apache Guacamole <https://guacamole.apache.org/>`_ REST API.
It allows AI assistants (Claude, GitHub Copilot, etc.) to manage Guacamole
instances — create and manage RDP/SSH/VNC/Telnet/Kubernetes connections, users,
user groups, and monitor active sessions.
